# 媒体归档 Lua 插件

插件收录指定会话中、由 LW Tools 的微信账号收到的普通图片、文件和视频引用。lwscdn Server 按消息日期把条目放进共享文件库的年、月、日三层目录，例如 `2026/11/14`。需要下载时，可在 lwscdn Client 发起「CDN 下载」，也可由 LW Tools 或其他插件发起各自的下载操作。

## 安装和试用

1. 准备支持 `wechat.message.observed` 的 LW Tools Desktop 或 Web，以及提供 `/v1/imports/wechat` 的 lwscdn Server。在 LW Tools 的「设置 → CDN」连接该 Server，启动要接收消息的微信账号。
2. 将 [media_archive.lua](media_archive.lua) 放进 LW Tools 实际加载的 [Lua 插件目录](../README.md#安装-lua-插件)。首次安装时点击「扫描插件」并启用「媒体归档」。如果已经安装，替换已加载的那份 `.lua` 文件，再在该插件的菜单点「重新加载」。
3. 从 Server 启动日志复制「归档令牌」，从「机器人」页复制接收账号 ID。
4. 打开「媒体归档 → 插件设置」，填写 Server 地址、归档令牌和接收账号。选一个测试会话，把它的 ID 加入「收录的会话」。列表字段每填一项都要回车或点击「添加」，看到条目出现在输入框上方再点击底部「保存」。
5. 让另一位成员在测试会话发送一张新图片或一个普通文件。在配对到同一 Server 的 lwscdn Client 中同步目录，再打开消息当天的年、月、日目录查看文件。

## 归档令牌

Server 首次启动时生成归档令牌并保存在文件库中，以后每次启动打印同一个值。多个接收账号可以共用这个令牌，插件仍按接收账号和会话列表筛选消息。设备配对码填到 Client，管理令牌填到 LW Tools 的 CDN 连接设置。升级后，插件里旧的签发凭据换成启动日志里的归档令牌即可。

## 每项填什么，留空会怎样

| 设置项 | 怎么填 | 留空的效果 |
| --- | --- | --- |
| Server 地址 | LW Tools 进程访问的 lwscdn Server 根地址。共享本机网络且使用默认端口时保留 `http://127.0.0.1:9088`。异机或独立容器使用 LW Tools 能访问的 HTTPS 地址，例如 `https://cdn.example.test`。 | 主动清空并保存后，命中的消息会报地址错误。初次打开设置显示的是默认值。 |
| 归档令牌 | 粘贴 Server 启动时打印的归档令牌。 | 命中的消息会报缺少凭据，在宿主的事件保留窗口内等待重试。 |
| 接收账号 | 接收消息的机器人微信账号 ID，例如 `wxid_receiver`。 | 所有账号的消息都跳过。 |
| 收录的会话 | 填会话 ID。Server 保存目录条目和上游下载引用，Client 可在引用仍有效且账号支持直传时发起「CDN 下载」。 | 跳过所有会话。 |

### 微信账号 ID 和会话 ID 从哪里找

「接收账号」用来选**哪个机器人账号收到消息**。在 LW Tools 的「机器人」页，点击账号卡片上的微信 ID 复制。你也可以打开消息详情，查看「账号」。

「收录的会话」用来选**从哪个聊天收到媒体**。在 Desktop 的「消息聚合」或 Web 的「消息」页，打开该聊天的一条消息，在详情里取「会话」字段。群聊通常形如 `12345678901@chatroom`，私聊填对方的 ID，例如 `wxid_friend`。群里有多位成员时，填一次群 ID 就会匹配该群收到的媒体，成员 ID 可以从详情的「发送方」另行查看。插件按完整 ID 匹配，昵称、群名称和 `*` 都只会被当作普通字符串。

### 日期目录和升级

Server 按消息的北京时间（UTC+8）归类。时间戳缺失或无效时，使用 Server 首次接收该请求的日期。同一天的消息复用同一个日目录。文件入库后可以在 Client 中重命名和移动，重复收到同一条消息时会返回原任务。

先更新 lwscdn Server，再重新加载新版 Lua 插件。旧版只填在「长期归档的会话」里的会话，如需继续收录，请将对应 ID 加到「收录的会话」。旧版已受理的任务按原配置处理，已有文件可在 Client 手动移动。

## 任务状态和排查

- **已收录**表示共享文件库里已有条目和下载引用。引用失效会影响后续直下。
- **完全没有任务**时，先检查插件是否启用、接收账号是否在线、是否保存了账号和会话列表，是否由另一个账号发送测试媒体。插件只处理 LW Tools 实际同步到的入站媒体。普通消息过滤在媒体观察之后，旧消息也必须由 LW Tools 实际同步到才会进入此流程。
- **请求未受理**时，可在 LW Tools 日志查看原因。`401` 检查归档令牌和 Server 地址，`403` 检查是否误用了设备凭据。地址、凭据或网络问题修复后，尚在事件保留窗口内的未确认事件会重试。超过窗口的事件缺口会记录到日志。
- **请求格式被拒绝**时，检查 Server 地址及两端版本是否支持媒体导入。插件会记录 `400` 或 `404` 并跳过该事件。
- **Server 已受理但同步后仍看不到文件**时，可用归档令牌查询 Server 的 `GET /v1/jobs`。若任务状态为 `failed`，在 `error` 字段查看原因，例如消息类型不支持、XML 无效或引用缺失。

把常用群成员或值班人员打包成一个分组，供多条「监控与转发」规则一键复用。
1
这是什么？
纯粹的「成员名单」：把各平台的成员账号（ID、用户名或昵称）归入同一分组，换班时只需改一处。
2
单独建组会发消息吗？
不会。分组本身只存成员名单；关键词和 @所有人 统一在「监控与转发」规则里配置，引用本分组后才会生效。
3
触发后会发生什么？
群里有人 @ 组内任意一位成员时，关联的转发规则会自动将消息转发到指定目标，且同组共享冷却防刷屏。
